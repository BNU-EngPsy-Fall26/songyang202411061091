# 午夜烘焙铺 · 最后一炉

工程心理学 · 作业一：构建一个信号检测论交互式实验网站

你是小镇烘焙铺的店主。甜点节前夜，冷库突然跳闸，你面前只剩最后 20 块蛋糕。
卖出一块坏蛋糕，可能有人会生病；扔掉太多，明天就交不出订单。

每局 20 次判断，结束后自动给出完整的信号检测论（SDT）统计结果。

## 一、运行环境

- 操作系统：Windows、macOS、Linux 均可
- 浏览器：Chrome、Edge 或 Firefox，建议使用较新版本
- 依赖：无需安装任何依赖，无需 Python、Node.js，也无需配置服务器

## 二、运行方法

1. 下载或 clone 整个项目文件夹到本地。
2. 进入该文件夹，双击 `index.html`。
3. 浏览器自动打开并显示登录界面，即表示运行成功。

也可以右键 `index.html`，选择“打开方式”，用浏览器打开。

## 四、操作说明

1. 在登录界面输入姓名和学号，或直接点击“游客模式”进入。
2. 在首页选择难度 `d'` 与坏蛋糕比例 `P(S)`，点击“开始今晚的最后一炉”。
3. 每试次先观察蛋糕上的可疑斑点，然后做出决定：
   - 按 `F` 或 `1`：可以卖（看起来没问题）
   - 按 `J` 或 `2`：不能卖（怀疑已经坏了）
   - 也可以直接点击页面下方的“可以卖 / 不能卖”按钮
4. 每次判断后会立即显示结果：拦下了、卖出去了、扔掉了或上架了。
5. 20 次结束后自动进入“今晚的结局”，展示剧情结局、混淆矩阵和完整 SDT 指标。
6. 从首页还可以进入“概念实验室”和“我的记录”。

## 五、SDT 术语对照

- 信号 S：坏掉的蛋糕
- 噪音 N：正常蛋糕
- 击中 H：坏蛋糕被判“不能卖”
- 漏报 M：坏蛋糕被判“可以卖”
- 误报 FA：好蛋糕被判“不能卖”
- 正确拒斥 CR：好蛋糕被判“可以卖”

## 六、常见问题

**双击后页面没有样式，或按钮点击没有反应？**

请检查 `css` 和 `js` 文件夹是否与 `index.html` 位于同一目录下。
运行时需要保留完整的目录结构，不能只单独复制 `index.html`。

**数据保存在哪里？**

所有记录只保存在本机浏览器的 localStorage 中，不会上传到任何服务器。
在“我的记录”页面可以导出为 CSV 或 JSON 文件。
